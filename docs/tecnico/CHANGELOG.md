# Registro de mudanças

## 2026-11-09

Propostas antigas: a da negociação de uma parte e a de terreno com uma parte só ganham a parte; as outras ficam sem parte (contam como de todas). Banco: `/mnt/project-files/propostas-partes/propostas-partes.sql`, rodado pelo Moises. Testes novos em `regras.sql`; os de "propostas encadeadas" mudaram para a regra nova. Segurança: tabela com RLS `ver` por empresa, sem escrita direta; exclusão só por RPC de editor, com auditoria.
